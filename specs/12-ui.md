# 12. User interfaces

**Admin** (`http://192.168.1.2:8080/admin`) — persons and weights, live usage,
devices with bind/unbind/block, route editor (upstream + per-class rates +
access), the domestic list, period settings with Jalali anchor, audit log,
drift report.

**Portal** (`http://portal.gate/`) — "این دستگاه: مهمان — ۳۲۰ مگابایت از ۱
گیگابایت باقی مانده", a copyable subscription link, and, when bound, the
person's remaining share. Persian first; English strings ship alongside.

**Subscription** — no UI, just the token URL and a copy button.
