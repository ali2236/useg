# 12. User interfaces

**Admin** (`http://192.168.100.2:8080/admin`) — persons and weights, live usage,
devices with bind/unbind/block, route editor (upstream + per-class rates +
access), the domestic list, period settings with Jalali anchor, audit log,
drift report.

**Portal** (`http://portal.gate/`, also `http://wifi.net/`) — "این دستگاه:
مهمان — ۳۲۰ مگابایت از ۱ گیگابایت باقی مانده", a copyable subscription link,
and, when bound, the person's remaining share plus the household list, where
each other person has a transfer button for giving them unused data. Persian first; English strings
ship alongside. The OS does not push a joined device here (see 03-addressing):
users open it by name (`portal.gate` or `wifi.net`).

**Subscription** — no UI, just the token URL and a copy button.
